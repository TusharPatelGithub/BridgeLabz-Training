## 📅 **Day 3 — Introduction to C# Programming**

> **Date:** _18/12/2025_  
> **Topic:** Basics of C# — Input/Output & Program Execution Flow

### 🧩 What I Learned

- 🟦 **C# Basics:** Structure of a C# program and `Main()` method
- ⌨️ **Input & Output:**
  - `Console.WriteLine()` for output
  - `Console.ReadLine()` for input
- 🔢 **Type Conversion:** Using `Convert.ToInt32()` and `Convert.ToDouble()`
- ⚙️ **Program Execution Flow:**
  - **Compiler:** Converts C# code into **IL (Intermediate Language)**
  - **IL / MSIL:** Platform-independent code
  - **CLR (Common Language Runtime):** Converts IL into machine code at runtime
- 🧠 **Concepts Covered:** Compiler vs Interpreter, IL, MSIL, and CLR working
